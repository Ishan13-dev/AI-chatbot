# 🤖 Gemini AI Chatbot

A lightweight, responsive AI chatbot built with **Python**, **Streamlit**, and the **Google Gemini API** (`gemini-3.6-flash`). Features real-time streaming responses and multi-turn chat history.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://ai-chatbot-mcf3rvwkzwgzwenxrwllwi.streamlit.app/)

## ✨ Features

- **Real-Time Streaming**: Responses stream token-by-token for a smooth user experience.
- **Conversation Memory**: Maintains multi-turn context throughout your session.
- **Fast & Scalable**: Powered by Google's `gemini-3.6-flash` model.
- **Easy Configuration**: Enter your API key securely via UI or configure it via environment secrets.

---

## 🛠️ Tech Stack

- **Python 3.10+**
- **Streamlit** (Web UI & deployment)
- **Google GenAI SDK** (`google-genai`)
